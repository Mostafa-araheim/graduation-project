1. HIGH-LEVEL PROJECT OVERVIEW
================================================================================

PROJECT NAME: Pharma (Pharmacy Management & E-commerce Platform)
DESCRIPTION: A graduation project to help pharmacies in Egypt:
  - List available medications
  - Allow consumers to check availability and prices
  - Provide AI-powered features for inventory management
  - Predict demand and manage surplus medicine redistribution

TECHNOLOGY STACK:
  - Backend: Spring Boot 4.0.2 (Java 25)
  - Database: PostgreSQL with PostGIS (Spatial data)
  - Caching: Redis
  - Payment Gateway: Stripe
  - Location Services: LocationTech JTS (GIS)
  - Build Tool: Maven
  - ORM: JPA/Hibernate
  - Mapping: MapStruct 1.6.3

5. IMPLEMENTED APIs AND THEIR PURPOSES
================================================================================

5.1 PHARMACY MANAGEMENT APIs:
   ✅ IMPLEMENTED:

   1. GET /api/v1/pharmacies/locations
      Purpose: Get all pharmacies with basic information
      Returns: List of PharmacyDto objects
      Auth: Public

   2. GET /api/v1/pharmacies
      Purpose: Search pharmacies with filters and pagination
      Params: name, minRating, isOpen, latitude, longitude, page, size
      Returns: Paginated PharmacyDto list
      Auth: Public
      Features:
        - Text search by name
        - Rating filter (0.0 to 5.0)
        - Open/closed status filter
        - Distance ordering (requires location)

   3. GET /api/v1/pharmacies/{pharmacyId}
      Purpose: Get detailed pharmacy information
      Returns: PharmacyInfo (pharmacy details, categories, address, reviews)
      Auth: Public

   4. GET /api/v1/pharmacies/{pharmacyId}/{categoryId}
      Purpose: Get products in pharmacy under specific category
      Returns: Paginated PharmacyProductDto list
      Auth: Public

   5. POST /api/v1/pharmacies/rating (OWNER)
      Purpose: Submit rating for a pharmacy
      Request: CreateRatingDto (pharmacyId, rating)
      Returns: PharmacyRating
      Auth: ROLE_CUSTOMER
      Features:
        - Updates average rating
        - Increments rating count

   6. POST /api/v1/pharmacies/review (OWNER)
      Purpose: Submit written review for a pharmacy
      Request: CreateReviewDto (pharmacyId, comment)
      Returns: ReviewDto
      Auth: ROLE_CUSTOMER
      Features:
        - Tracks reviewer name
        - Increments review count

   7. POST /api/v1/pharmacies/bulk
      Purpose: Bulk create multiple pharmacies
      Request: List<CreatePharmacyRequest>
      Auth: Public
      Note: Data seeding endpoint

   8. POST /api/v1/pharmacies (OWNER)
      Purpose: Create new pharmacy (owner)
      Request: CreatePharmacyRequest (full pharmacy details)
      Returns: PharmacyDto
      Auth: ROLE_OWNER
      Features:
        - Creates associated inventory
        - Sets owner relationship
        - Creates address

   9. DELETE /api/v1/pharmacies/{pharmacyId} (OWNER)
      Purpose: Delete pharmacy (owner only)
      Auth: ROLE_OWNER
      Features:
        - Validates owner access
        - Cascading delete (address, inventory, products)

   10. PATCH /api/v1/pharmacies/{pharmacyId} (OWNER)
       Purpose: Update pharmacy details (partial)
       Request: UpdatePharmacyRequest (optional fields)
       Returns: PharmacyDto
       Auth: ROLE_OWNER
       Features:
         - Update name, image, hours
         - Update address details
         - Update location (lat/lon)
         - Automatic geometry update

   11. GET /api/v1/pharmacies/owner (OWNER)
       Purpose: Get all pharmacies owned by authenticated user
       Returns: List<PharmacyDto>
       Auth: ROLE_OWNER

   12. GET /api/v1/pharmacies/owner/{pharmacyId} (OWNER)
       Purpose: Get specific owned pharmacy details
       Returns: PharmacyDto
       Auth: ROLE_OWNER
